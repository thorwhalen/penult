penult.github#

GitHub, through the gh and git commands: read an issue, post or edit a comment, find raw URLs.

Every function takes a runner (the shape of subprocess.run()) so tests run without a network and another transport can be dropped in. The default needs an authenticated gh.

>>> parse_issue_url("https://github.com/octo/essays/issues/30")
('octo', 'essays', 30)

penult.github.raw_url_base(checkout, folder)[source]#

The raw.githubusercontent.com prefix for files in folder at the checkout’s commit.

The commit, not the branch, so the links keep working after the branch is merged and deleted.

>>> raw_url_base({"root": "/r", "owner": "o", "repo": "e", "branch": "main", "sha": "abc123"}, Path("/r/docs/an essay"))
'https://raw.githubusercontent.com/o/e/abc123/docs/an%20essay/'

str

penult.github.unpushed(checkout, paths, *, runner=<function run>)[source]#

Which of paths are not yet committed and pushed to the branch’s upstream.

A raw URL only works for a file that is on GitHub, so post refuses while any image it references is in this list. Paths are compared in git’s own form (forward slashes, unescaped thanks to -z).

Return type:

list[str]
